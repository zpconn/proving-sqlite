# §1.9 Tools (2026-11-08)

`tools/tests/test_tools.py` (run with `GNUMAKEFLAGS=--no-print-directory`): 52/52 pass. It builds a scratch root with a toy sqlite3.c (toy functions, not SQLite code) and checks:
- **check_overlay.py:** passes upstream plus a multi-line span. It fails a one-space change, code hidden between a commented `PROOF(` and `)`, and an upstream that doesn't match pin.txt. Code inside a span passes check_overlay and fails scan.
- **prove.py and make:** passes an enforced contract at a 2-byte footprint and fails it at 1 byte. Loop contracts pass, and a false invariant fails. It fails a call to a bodyless function, a Makefile variable outside the schema, a check-disabling SOLVER, and an ENFORCE paired with another function's contract. The RESULT line comes last.
- **coverage:** see 07-coverage.md.
- **scan.py rejects:** an assume outside SETUP; a SETUP assume that subscripts or dereferences data; `#pragma CPROVER`; a define before sqlite3.c; a harness defining a function SQLite calls; a macro hiding an assume; calloc and file-scope buffers; a contract declared in a harness; `--no-bounds-check` in CHECKS; a CHECKS line missing unwinding assertions; an extra `-D` in CONFIGS; span contents (an assignment, clauses out of order, an assume, an unknown call); a span after an `if` or after a do-while condition; a span in a function no card names; with `--card`, a span changed in another card's function; a boundary contract without a ledger entry, or naming one LEDGER.md lacks; replacing a callee no card enforces.
- **mutate.py:** an out-of-bounds mutant is killed; a functional-only mutant survives and fails the run unless it carries a reviewed equivalence argument; an ambiguous mutant is an error; a planted shift bug is killed. The overlay's hash is unchanged after every run.
- **lock.py:** detects a changed tool and a new file under a frozen path, and exempts sessions.toml.
- **make targets:** `make prove`, `make coverage`, `make probe`, `make gate [CARD=C-NN [BASE=<commit>]]` (tools/gate.py), and `make -C proofs/C-NN prove|coverage [CONFIG=]` (proofs/Makefile.common). Each ends with a RESULT line.
- **RESULT line caveat:** under `make -C`, GNU make 4.3 prints "make: Leaving directory" after the RESULT line, and nothing in a Makefile stops it; only the environment does (`GNUMAKEFLAGS=--no-print-directory`). campaign.py sets it for every session and gate. On FAIL, make also prints its "Error" line on stderr.
- **A CBMC quirk** seen while testing mutants: a statement with an undefined shift also reported dereference failures for `p[1]` in the same expression, which pass without the mutant. The kill is still real; the shift failure is listed too.
