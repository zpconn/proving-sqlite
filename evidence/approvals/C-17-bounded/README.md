## Beyond what was asked, for the auditor to judge
- **A constant value given to an input is a bound.** C-17's proofs fix their inputs with plain assignments (`nField = 3;`), which scan didn't treat as narrowing at all. Rule 16 now refuses, in every proof, a constant assigned to a value input, whether a local or a field of an input object, unless BOUNDS fixes it. A pointer set to 0 is not refused. No merged harness assigns one, and all 15 merged cards still pass scan. Tests: `n = 5;` in an unbounded proof is refused; a fixed `n = 5;` passes; `n = 6;` against a fixed 5 fails.
- **Scratch test repos start with an empty EXCEPTED_FAILURES** (test_tools.py `T.fresh`), so C-17's real entry doesn't fail the legacy toys that use card C-17. Tests that need a table set their own.
