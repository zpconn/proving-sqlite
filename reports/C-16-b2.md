## Contract

- A complete writable UnpackedRecord. External BtreeIndexMoveto passes its
  unpacked search key at upstream/sqlite3.c:79278; this remains a caller obligation.
- A readable KeyInfo header plus one **whole** aColl entry, expressed only as
  `r_ok(p->pKeyInfo, SZ_KEYINFO(1))`. KeyInfoAlloc's layout at 150534–150544
  motivates the allocation obligation.
- A complete readable first Mem. The unpacked-search-key description at
  19706–19717 motivates the presence of a first field.
- One readable sort flag. KeyInfoAlloc lays out the flags at 150540.
- At least one of MEM_Int/Str/Real/IntReal/Null/Blob when the specialized string
  path is eligible. nAllField>13, BIGNULL or a non-NULL first collation exempts
  an otherwise typeless Mem. Mem's type definitions at 24540–24587 and the
  assertion at 93047 motivate this obligation.

There are no in-scope callers to establish these premises; the ledger draft
below states them. NOTES.md preserves the round-1 independent clause-deletion
counterexamples, explicitly labeled as round 1, including the typeless string
case. Those runs are recorded in reports/C-16-b1.md, not rerun here.

Ensures one of the three actual comparator pointers. The integer case has
MEM_Int, nAllField<=13 and the copied u.i. The string case has MEM_Str without
MEM_Int/Real/IntReal/Null/Blob, nAllField<=13, NULL first collation, and copied
z/n. Each specialized case excludes BIGNULL and has opposite r1/r2, with r1=1
for nonzero sort flags and -1 otherwise. Assigns exactly r1, r2, u and n.
Generic selection need not initialize caches. No string readability, nonnegative
length, serialized-record validity or record padding is established here.

Tested native one-byte-short probe, unmodified upstream, x86_64:

```c
#include "sqlite3.c"
int main(void){
  UnpackedRecord *p = calloc(1, sizeof(*p));
  KeyInfo *k = malloc(SZ_KEYINFO(1)-1);
  Mem *m = calloc(1, sizeof(*m));
  u8 *sort = calloc(1, 1);
  if( !p || !k || !m || !sort ) return 2;
  memset(k, 0, SZ_KEYINFO(1)-1);
  k->nAllField = 1;
  k->aSortFlags = sort;
  m->flags = MEM_Str;
  p->pKeyInfo = k;
  p->aMem = m;
  RecordCompare cmp = sqlite3VdbeFindCompare(p);
  printf("string comparator: %d\n", cmp == vdbeRecordCompareString);
  free(sort); free(m); free(k); free(p);
  return 0;
}
```
