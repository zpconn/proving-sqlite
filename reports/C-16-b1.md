## Contract

Requires complete writable UnpackedRecord storage, readable KeyInfo storage
including aColl[0], a readable first Mem, and one readable sort flag. When the
small-schema, non-BIGNULL, no-collation string path is eligible, aMem[0] must
have at least one of the six SQL type bits. No restrictions on string/blob
bytes, integer values, string lengths, or string-pointer values are imposed.

Ensures the return is sqlite3VdbeRecordCompare, vdbeRecordCompareInt or
vdbeRecordCompareString. The integer case guarantees MEM_Int, the cached
integer, and nAllField<=13. The string case guarantees MEM_Str, absence of
MEM_Int/Real/IntReal/Null/Blob, NULL aColl[0], cached z/n, and nAllField<=13.
Either specialized case guarantees no BIGNULL and r1/r2 of opposite sign,
with r1=1 for nonzero sort flags and r1=-1 otherwise. Assigns exactly the
fields the implementation writes: r1, r2, u, n. Generic selection need not
initialize those caches. The function does not establish string readability,
nonnegative n, or a record-byte/header/padding property for later comparators.

Every requires is an external caller obligation, because C-16 has no in-scope
callers. Source motivation and independent clause-deletion counterexamples are
in NOTES.md's table; the exact combined obligation is drafted below. These
are conditional proofs of a nondeterministic input graph of separate typed
allocations; no input data bytes are initialized or constrained in the harness.
