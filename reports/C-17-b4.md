# C-17 round 4: sqlite3VdbeRecordCompareWithSkip (builder on Claude, Opus 5.5)

Nothing is *proved* this round. Zach's advance decision applies: B1 still holds under the legacy engine, so C-17 goes
to a bounded P1. This round measures that bounded P1 and asks for the decisions it needs. The decisions are in §7.

Summary:
- **B1 under legacy (*tested*, §1):** the T-010 toys were rerun under both engines, plus two new ones. The per-field
  obligations still can't be stated for an unbounded nField:
  - MiniSat ignores a forall whose bound is symbolic, even over integers;
  - Z3 rejects quantified pointer primitives and aborts on the equality variant;
  - is_fresh can't sit inside a quantifier.
- **B2 is settled:** every memcmp call is replaced by A-006's contract, so no run uses CBMC's per-byte model. With
  memcmp, A-003 and isAllZero all contracts, **string and blob lengths need no bound (L = none)**. Every run below
  leaves them unbounded.
- **B3 / T-006:**
  - The legacy loop contract on the real loop runs out of memory at nField ≤ 2. The havocked pRhs is dereferenced
    over every object (§2).
  - So the bounded proof unwinds the loop instead, with one proof per (bSkip, nField). This keeps every pRhs offset
    constant, which is what makes it tractable.
- **F-001 is now shown by CBMC too.** Every bounded run fails only the signed-overflow check on `rc = -rc` (upstream
  92793): once per proof under DFCC, once per unrolled iteration under legacy-unwind. Its trace has vdbeCompareMemString (A-003) returning
  −2147483648. No requires excludes it (builder rule 8), so no bounded run can end with 0 failed. Decision 4 asks how
  to record it.
- **Measured (§4):**
  - **Current tools (DFCC):** K ≤ 5 for prove, and K ≤ 3 for coverage. Peak memory grows about 2.5 GB per field
    from DFCC's per-call write sets;
    nField = 6 needs 13.3 GB, over prove.py's 12 GB cap.
  - **Legacy contracts with the loop unwound before enforcement:** nField = 16 in at most 171 s and 3.6 GB.
    nField = 24 takes 9:54 (the 600 s timeout) and nField = 32 takes 27 min and 16.4 GB. This order needs a
    tools/prove.py change.
- **Proposal:** K = 16, L = none, on legacy-unwind, plus the native random test past the bound (§5). If Zach wants no
  tools change, K = 5 on DFCC (coverage then needs a larger memory cap).

## 3. The bounded proof (committed at K = 3: the largest K whose prove and coverage both run on today's tools)

**Harness** (proofs/C-17/harness.c; generated by tmp/gen/gen.py; five entry functions, harness_b0n1..b0n3 and
harness_b1n2..b1n3). Each one, in SETUP:
- assigns `bSkip` and `nField`, assumes `nKey1 >= 0` and `nAllField >= 1`;
- mallocs:
  - the record at exactly max(nKey1, 10 + (bSkip != 0)) + 8 bytes;
  - pPKey2;
  - aMem at exactly n Mems;
  - the KeyInfo at exactly `sizeof(KeyInfo) + sizeof(CollSeq*)*min(nField, nAllField)` bytes, which is

- for each field k: `z_k = malloc(n_k)` with `n_k >= 0` unbounded, and `m_k = mem + k; m_k->z = z_k; m_k->n = n_k;`;
- for each aColl entry: `c_k = malloc(sizeof(CollSeq))` (NULL or a CollSeq, by --malloc-may-fail), and
  `ki->aColl[a_k] = c_k`, where `a_k = nA > k ? k : 0` and the writes run high to low.

- `OBJECT_BITS := 12`;

1. `nKey1 >= 0 && r_ok(pKey1, max(nKey1, 10 + (bSkip != 0)) + 8)`. This is A-001 for this card: S = 8, with a floor of

## 5. Tested past the bound (native)

tmp/native/past.c (quoted in full below) runs on unmodified upstream with campaign.py's sanitizer flags. Each trial
draws:
- bSkip, then nField in [1 + bSkip, NMAX] and nAllField;
- random Mems: Int, IntReal, Real, Str, Blob, Blob|Zero, Null, or random flags;
- random sort flags, and aColl entries NULL or a collation.

Allocations are the contract's exact footprints: the record at max(nKey1, 10 + b) + 8 random bytes, the KeyInfo at
SZ_KEYINFO(min), each z at n bytes. Half the trials are "deep": equal NULL prefixes, so the loop runs to the end.

Result: `trials=300000 NMAX=120 nonzero=234974 largest nField reaching the end=120`, with no ASan or UBSan report.
Collations return values in [−1000, 1000]; F-001's INT_MIN is excluded here, as the known finding. I propose this
test, or the orchestrator's equivalent, as the bounded P1's "native tests past the bound". It needs a home that isn't
on my May change line (tests/native/?), which is decision 1(c).

Build and run: `cc -std=gnu11 -g -O1 -fno-omit-frame-pointer -fsanitize=address,undefined -fno-sanitize-recover=undefined -I upstream past.c -o past -lm -lpthread -ldl`, then `./past 300000 120`.
~~~
/* C-17 round 4, scratch: native random test past the CBMC bound. Unmodified upstream, ASan+UBSan.
   Each trial: nField in [1+bSkip, NMAX], random Mems (Int, IntReal, Real, Str, Blob, Blob|Zero, Null, random flags),
   random sort flags, KeyInfo at exactly SZ_KEYINFO(min(nField, nAllField)), record of random bytes at exactly
   max(nKey1, 10 + (bSkip != 0)) + 8 bytes (A-001 slack), string/blob buffers at exactly n bytes.
   Collations return values in [-1000, 1000] (F-001's INT_MIN is a known finding; excluded here). */
#include "sqlite3.c"
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
static unsigned long long rs = 88172645463325252ULL;
static unsigned rnd(void){ rs ^= rs << 13; rs ^= rs >> 7; rs ^= rs << 17; return (unsigned)rs; }
static int coll(void *p, int n1, const void *a, int n2, const void *b){
  int n = n1 < n2 ? n1 : n2, c = memcmp(a, b, n); (void)p;
  return c ? (c < 0 ? -1 - (int)(rnd() % 1000) : 1 + (int)(rnd() % 1000)) : n1 - n2; }
static const u16 kinds[] = { MEM_Int, MEM_IntReal, MEM_Real, MEM_Str, MEM_Blob, MEM_Blob|MEM_Zero, MEM_Null };
int main(int argc, char **argv){
  int trials = argc > 1 ? atoi(argv[1]) : 100000, NMAX = argc > 2 ? atoi(argv[2]) : 200, t, nonzero = 0, maxi = 0;
  CollSeq cs; memset(&cs, 0, sizeof cs); cs.enc = SQLITE_UTF8; cs.xCmp = coll;
  for(t = 0; t < trials; t++){
    int bSkip = rnd() & 1, nField = 1 + bSkip + (int)(rnd() % (NMAX - bSkip)), nAll = 1 + (int)(rnd() % (NMAX + 2));
    int nA = nField < nAll ? nField : nAll, i, j, nKey1;
    /* records: mostly well-formed-looking headers of small serial types, sometimes pure random bytes */
    nKey1 = (int)(rnd() % (4 * nField + 40));
    size_t ext = (size_t)(nKey1 > 10 + bSkip ? nKey1 : 10 + bSkip) + 8;
    unsigned char *rec = malloc(ext);
    for(j = 0; j < (int)ext; j++) rec[j] = (unsigned char)rnd();
    int deep = rnd() & 1, tail = (int)(rnd() % 4);

1. **The bound.** Proposal: **K = 16, L = none.**

     K = 24 and 32 are not: b0n24 took 9:54, at the 600 s timeout, and b0n32 took 27 min and 16.4 GB. Symex time grows with the contract's unrolled clauses.

   - p is a local holding a malloc result;

   - c is a local holding a malloc result or 0.

   Nothing else changes. It constructs a pointer table entry, never data bytes. Without it, no harness can give a
   non-NULL collation to the field at 92729/92734.
3. **Engine** (if K > 5): a tools/prove.py pass for legacy proofs with `LOOPS := unwind`. It would run

   - (c) C-17's P1 stays "proved but for F-001" in RESULTS.md.
